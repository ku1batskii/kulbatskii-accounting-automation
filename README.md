# KULBATSKII · Автоматизация бухгалтерии

Презентационный сайт концепции автоматизации бухгалтерских процессов: целевая модель, пилот, KPI, экономика, дорожная карта и контрольные точки Gate.

## Стек

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4

## Локальный запуск

```bash
npm install
npm run dev
```

Сайт будет доступен по адресу `http://localhost:3000`.

## Проверка production-сборки

```bash
npm run build
npm run start
```

## Деплой

Проект подготовлен для импорта из GitHub в Vercel. Vercel автоматически определяет Next.js и использует команду `npm run build`.
